# helloworld

This is a simple 'helloworld' project.

It includes a file named `hello.txt`, which contains a simple text message.

Oh it's a wonderful world

## How to Run

To run the script, execute the following command in your terminal:

```bash
python run.py
```

or

```bash
python3 run.py
```

This script will read the content of `hello.txt` and print it to the console.
